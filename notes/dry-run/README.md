# Earlier feasibility run

[The summary](summary.pdf) synthesises the earlier feasibility analyses.
It uses the original short-tail calibration and precedes the current
handout's common early-decline priors. Its numerical follow-up requirements
should therefore be interpreted in that original setting.

The current methodological specification is in
[the handout](../handout.pdf). The new single-participant prior pilot is
reproduced with `scripts/01-prior-pilot.R` and
`scripts/02-prior-pilot-report.R`; its generated outputs remain in the
ignored `results/prior-pilot/` directory.
