# Analysis figure plans

proposed analysis figures. [Version 1](analysis-schematic-v1.png) is the
earlier draft, retained for comparison.

probabilities and operating points drawn here are not computed analysis
results. The handout defines the current methodology; generated pilot
figures are saved separately under `results/prior-pilot/`.
