# Duration of antibody protection project

This repository supports the Duration of Antibody Protection project at the Nagoya-Oxford Workshop 2026.

## Contributing

Fork the [main repository](https://github.com/will-s-hart/antibody-duration-project), create a branch in your fork, and open a pull request from that branch against `main` in the main repository.

If [pixi](https://pixi.prefix.dev/latest/) is not already installed on your device, install it, then set up the project environment from the repository root with:

```sh
pixi install --locked
```

Prepend `pixi run` to commands that should run in the project environment; for example, `pixi run python [XX]`.
